# 🛒 Minecraft Server Shop

Jednoduchá webová nástenka pre Minecraft server, ktorá slúži ako vizuálny cenník pre hráčov.

## 📌 Čo táto stránka robí?
- **Zobrazuje ponuku predmetov:** Prehľadne rozdeľuje predmety do kategórií (Enchanty, Bloky, Nástroje).
- **Ukazuje ceny:** Pri každej položke je jasne vidieť názov, počet/úroveň a cena v diamantoch.
- **Minecraft dizajn:** Web využíva hlinené pozadie, drevené menu, vlastný font a efekty trblietania na očarovaných knihách.

*Poznámka: Ide o čisto informačnú stránku bez funkcie reálneho nákupu.*
